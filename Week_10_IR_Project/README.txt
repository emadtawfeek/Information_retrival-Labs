Information Retrieval - Week 10
Python 3.10 or later. Standard library only. No internet required.
Extract the ZIP first. Open a terminal in this week folder.
Run: python main.py
Starter: python lab10_exercises.py
On Windows, py -3 may be used instead of python.
Keep data/docs folders beside the Python files. Paths use the script location,
so running from a different working directory also works.
Starter programs run but contain intentional TODOs and placeholder results.
They do not import a solution. Complete them using the laboratory sheet.
Interactive mode: python main.py --interactive
Type quit to exit.
Custom query: python main.py "python data analysis"
Keep all seven Python modules together. Missing/empty docs reports an error.
Evaluation uses data/relevance.json when present; unjudged queries still rank.
