# Explained Student Lab Sheets

Ten English student worksheets accompany the weekly laboratory programs. Each worksheet
has five A4 pages and is available as editable Word and matching printable PDF.

Start with [Lab 0 setup](Lab_00_Setup/README.md), then use the worksheet for your week.
The worksheets include explained concepts, worked examples and output, a code walkthrough,
guided tasks, checkpoints, a test record, common errors, independent exercises,
submission instructions, and an optional challenge. Answer spaces are left for students.
