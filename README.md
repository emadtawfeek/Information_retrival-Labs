# Information Retrieval Labs

Ten undergraduate Python laboratories, from file handling and regular expressions
through indexing, ranking, evaluation, and a small search engine.

Start with [Lab 0 setup](Lab_00_Setup/README.md) and the
[Python and course setup guide](Lab_00_Setup/Setup_Guide.pdf)
([Markdown version](Lab_00_Setup/Setup_Guide.md)). The labs require Python 3.10
or later and use only the standard library and included local modules. Lab 0
contains the [requirements file](Lab_00_Setup/requirements.txt) listing every
lab import and a verified official Python 3.13.15 Windows x64 installer.

The [course README](Course_README.md) lists every weekly command, explains the
data folders, and documents the teaching progression. Each week contains an
editable lab sheet, a PDF copy, runnable code, exercises, sample data, and
expected output.

Use the [explained English student worksheets](Student_Lab_Sheets_Index.md) for
step-by-step practical work. Every week includes a five-page Word worksheet and
matching PDF, with worked examples, guided activities, checkpoints, common errors,
and submission instructions.
